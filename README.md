# Bookworm - книжный интернет-магазин
## 1.Описание проекта 
Bookworm — это книжный интернет-магазин, предназначенный для просмотра каталога книг, оформления заказов, расчёта их стоимости и отслеживания статусов заказов.

## 2. Участники команды

* Аня — Lead Developer (ведущий разработчик)
* Настя — Data Developer (разработчик обработки данных)
* Алёна — QA Engineer (инженер по качеству)

## 3. Распределение обязанностей

Настя — каталог книг и контроль остатков

* Разработка каталога книг
* Добавление и просмотр книг
* Поиск книг
* Контроль количества книг на складе

Алёна — оформление заказов

* Выбор книг для заказа.
* Указание количества экземпляров.
* Проверка наличия книг.
* Расчёт стоимости заказа.
* Создание заказов.

Аня — статусы заказов и отчёты

* Просмотр заказов
* Изменение статусов заказов
* Проверка допустимости изменения статусов
* Формирование отчётов
* Подсчёт количества и общей стоимости заказов
* Сборка общей версии проекта

## 4. Основные модули проекта

1. Каталог книг и контроль остатков
2. Оформление заказов и расчёт стоимости
3. Обработка статусов заказов и формирование отчётов

## 5. Используемые технологии

* Python
* GitHub

## 6. Статус проекта

Проект находится на стадии разработки
